# Security Policy

This repository is a **current, pre-release** project under active
development. There is no long-term-support version and no guaranteed
maintenance window for older states of the code.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through a public GitHub
issue.

If GitHub's Private Vulnerability Reporting is enabled for this repository,
use it to report a vulnerability privately:
[https://github.com/ShenJun93/tieu-tien-ky-game/security/advisories/new](https://github.com/ShenJun93/tieu-tien-ky-game/security/advisories/new)

This project does not currently commit to a specific response-time
service-level agreement, a bug-bounty program, or a CVE-assignment process.
