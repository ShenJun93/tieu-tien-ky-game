# Eco-4: what TTK hand-rolls today (read-only audit, 2026-09-26)

Audit of `Assets/_Project`, `Assets/Editor`, `Packages/manifest.json` and `ProjectSettings` at `main` 27e8d6b (after R0.3). Nothing was changed. Line counts are from `wc -l`. Evidence, not instructions.

## Key facts

- **One runtime assembly.** `TieuTienKy.Gameplay.asmdef` holds Core, Diagnostics, Gameplay, Input and Presentation (Presentation files even use the `TieuTienKy.Gameplay` namespace). It references `Unity.InputSystem` and `Unity.Netcode.Runtime`. `Assets/Editor/*.cs` has no asmdef.
- **Shipped scenes:** `Boot` → `MainMenu` → `Arena_VerticalSlice_01`. Not shipped: `P0A_Greybox` (regression sandbox) and `Arena_Network_01` (NGO duel).
- **UI text** is legacy `UnityEngine.UI.Text` with `LegacyRuntime.ttf`; no TextMeshPro.
- **Not installed:** Cinemachine, Addressables, Localization, Timeline, any tween library.
- **Player settings:** new Input System only, ARM64, minSdk 25, product name "Tieu Tien Ky P0A", no application id, fixed timestep 0.02.

## Why the build looks like a prototype

The look is **generated by C#**, not authored:

- `Assets/Editor/VerticalSliceContentBuilder.cs` (922 lines) builds the enemy, boss and CultivatorProxy prefabs from primitives, writes AnimationClips keyframe by keyframe and AnimatorControllers in code, and builds the Boot/MainMenu/Arena scenes.
- `Assets/Editor/StageABArenaVisualBuilder.cs` (215) bakes the arena from built-in Cube/Cylinder/Plane meshes.
- `Assets/_Project/Editor/Authoring/ProductProofCombatHudAuthoring.cs` (707) builds the HUD prefab in code.
- `Assets/Editor/StageABAudioBuilder.cs` (269) synthesises the 14 WAVs in `Resources/Audio` (the Slice 009 playtest rated audio NO).
- At runtime, telegraph cubes, event markers, particle bursts, Storm Control quads and blessing rings are created per use with `CreatePrimitive` / `new ParticleSystem` and destroyed afterwards; no prefabs, no pooling.
- Every character prefab uses `Resources/Materials/P0A_Greybox.mat` (custom **unlit** shader), so characters receive no lighting. `ToonPrototype.shader` from R0.3 is not referenced anywhere yet.

## Timing

Everything runs in `Update` on `Time.time` / `Time.deltaTime` (sequencers, cooldowns, movement, `Physics.OverlapSphere` hit checks). Only `WaterZone` uses `FixedUpdate`. No Rigidbodies. Because hitstop scales global time, cooldowns and sequencers stretch during the freeze.

## Test impact

Pure logic is well covered (EditMode 183/183 after R0.3). Uncovered or weak: HitStop, HitFeedbackFlash, CombatAudio, PrimitiveTelegraphVFX, camera runtime, Netcode, all editor generators. About 7 test files depend on the greybox bootstrapper.
